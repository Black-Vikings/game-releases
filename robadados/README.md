# Robadados

Party brawler online para cuatro. **Un solo dado en todo el mapa**: para avanzar
tu ficha hay que quitárselo a los otros tres.

## Requisitos

- Windows 10/11, Linux o macOS, 64 bits
- Cuatro jugadores por red, o menos con bots llenando la mesa
- Un mando o teclado y ratón por persona

## Cómo se juega con amigos

Uno crea la sala y pasa el código; los demás lo pegan y entran. Con Steam
abierto el código es una invitación de Steam y se puede mandar por la lista de
amigos.

Las versiones están en los [releases](../../releases) de este repositorio.
